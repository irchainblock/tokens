# توکن‌های شبکه تبادل اطلاعات توزیع‌شده (بلوک)

به مخزن رسمی معرفی توکن‌های ثبت‌شده در **شبکه تبادل اطلاعات توزیع‌شده (بلوک)** خوش آمدید.

## 🧩 درباره شبکه بلوک

**شبکه بلوک** (Block Enterprise Blockchain) یک بلاکچین خصوصی/اختصاصی مبتنی بر الگوریتم اجماع **PoGA** است که با هدف تبادل امن، شفاف و توزیع‌شده داده‌ها و تراکنش‌ها طراحی شده است. این شبکه به سازمان های عضو امکان می‌دهد تا توکن‌های اختصاصی خود را ایجاد، ثبت و مدیریت کنند.

## 🎯 هدف این مخزن

این مخزن شامل اطلاعات رسمی، عمومی و فنی درباره توکن‌های صادر شده در شبکه شتات است.

### اطلاعات موجود شامل:

- نام و نماد توکن‌ها  
- آدرس قرارداد هوشمند توکن  
- تعداد اعشار (Decimals)  
- مجموع عرضه (Total Supply)  
- تصویر و لوگو توکن (در صورت وجود)  
- اطلاعات مالک/توسعه‌دهنده (در صورت تمایل)
